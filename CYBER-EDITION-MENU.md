# AflatoonMubdi V2 — Cyber Edition

The in-app panel uses a black / neon-blue cyber-security visual identity, Arabic navigation labels, terminal-style title animation, and visible ownership credit for AFLATOON (أفلاطون). The Kali Linux reference is stylistic/inspired-by only; this project is not affiliated with or endorsed by Kali Linux.

## Navigation
- شبكة: DNS, network status, and WireGuard companion actions
- صوت: outgoing microphone processing
- غرفة: local incoming voice processing
- وقت: input/output delay and tempo controls
- أداء: in-process clock controls
- حول: project information and local profiles

The interface does not make inactive capabilities functional by appearance alone. Network boost is socket tuning, not a VPN; DNS changes are limited to the hooked process; game-clock changes do not lower network ping.
